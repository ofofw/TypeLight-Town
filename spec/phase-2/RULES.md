# 精确行为规则

## 内容开放与题单

题目身份是 content.json 的 item.id；同一词在不同任务重现时共享复习记录。newItemIds 表示该任务首次引入的内容，不表示每次重玩都是新词。第一阶段学过内容不自动开放第二阶段题库。

故事题单：重点池分配 ceil(N×0.7) 题，复习池分配余量。无复习池则全部从重点池抽取。为保证每项新内容实际出现，先让每个重点项目出现一次，再补足重点配额。池内按当前累计选取次数最少优先，再用有种子的随机数打破平局；复习池同法。最终排列每一步题数固定，优先放置剩余次数最多且不同于上一项的项目；并列按种子随机。配额无法避免相邻相同时，先以同池其他项替换一次，再排列；单项池才允许相邻相同。保存题单本身，不以未来配置重新生成旧任务。

每次任务实例使用新的种子；随机源沿用项目现有 RNG，注入显式种子。同一配置版本、种子、已学集与时间快照生成相同题单。新增内容在孩子首次进入该题后标记 exposed，在正确完成该题后标记 learned；委托和专项只使用 learned。固定配置的 reviewItemIds 仅定义候选范围，运行时还须与 learned 求交集。专项目录还须满足该标签的教学已展示。

无题池不能开始任务或发奖，显示“先完成一个相关故事任务吧”。重新开始会重新生成实例，不能覆盖原实例完成历史。

## 委托、专项和复习

配额比例固定为易错 40%、到期复习 40%、其他已学 20%（前两项向下取整，余量归最后项）。2026-11-16 委托题量下调后的实际取值：N=12 时配额为 4 易错、4 到期、4 其他；N=9 时为 3、3、3。易错仅包含最近最多 20 个完成 occurrence 中有至少一次首次失败或显式求助的内容，无此记录不进入易错池。

三个候选池可有相同 item，但同一抽取槽只归一个配额。池内先轮询全部候选再重复；排序并列按稳定 ID。到期池按 dueAt 升序、ID 升序；其他池按 lastPracticedAt 升序（未记录最先）、ID 升序。缺额填入全部已学池后统一执行避免相邻规则。专项先按类别过滤，再执行相同算法。

每道题 occurrence 正确完成后更新复习。首次完成安排 1 天后；已有记录且本次首次提交正确、没有显式帮助时，按 1→3→7→14→14 天推进，否则安排 1 天后。同一 item 同一任务实例最多提高一次间隔；同实例任一 occurrence 失败/求助则本实例最终间隔回到 1 天，不能靠连续刷相同题立即升到 14 天。

时间为毫秒 UTC，1 天固定为 86400000ms，不受时区夏令时影响。计算时间取 max(当前系统时间, 存档最大观察时间)；向前调整可以让复习到期，但不发任何额外奖励；回拨不减少既有进度。无后台定时器、无缺席惩罚。

## 状态机和输入提交

任务状态：intro → active → step-complete → active → result；active 可到 paused，paused 可恢复；任意未完成状态可明确 abandon。最后一题完成同时产生原子结算并进入 result。三步结束画面均有继续按钮，最后一次确认已完成任务，即使关闭结尾动画也不会漏奖。按住 Enter 的 repeat 事件不反复提交或跳步。

每题状态包含 occurrenceId、targetId、draft、firstSubmitted、firstCorrect、wrongSubmissions、editOperations、helpUsed、completed、compositionActive。composing 时不比较答案、不记录错误、不清空输入。input 框无需控制每个字符是否正确，错误只在主动有效提交时记录。

实现维护“Enter 按下→抬起”生命周期。若 keydown.isComposing、内部 compositionActive 或兼容性 keyCode 229 表示组字，则本次 Enter 周期为选字周期，直到 keyup 都禁止交卷；不得在 compositionend 直接调用 submit。Safari 等可能在 keydown 前发 compositionend：遇到 compositionend 标记一次键盘提交保护，保护期间紧邻的 Enter 周期仅解除保护、不交卷；触摸/鼠标确认需 composition 完成后重新点击，并可显式确认当前文本。这是保守的防误交策略，允许个别选字路径多按一次 Enter，不能误交导致错误题或跳题。恢复焦点/失焦清理按键按住状态。实际设备事件顺序用验收证据覆盖。

按钮 mousedown/pointerdown 若发生于组字期间不得使后续 click 直接交卷。composition 完成但仍需保护时显示“选好字后，点确认”，保持按钮可用。点击确认后不让输入框焦点永久丢失。粘贴拦截基于 paste/insertFromPaste，而非按输入长度猜测；拖放文本、浏览器填充与语音输入不作为规定的键盘练习路径，禁用可控的自动填充/自动更正/拼写修正，不声称能可靠侦测所有系统替换。

英文 NFC 后逐字符严格比较；中文也严格比较 NFC 后目标字符，不 trim 两端。空字符串或全空白只提示“先输入内容”，不提交统计。中文误输入拼音时提示“切换到中文拼音输入法，选好汉字再确认”，有效非空提交计为一次未匹配，不推断实际输入法状态。

分段帮助只显示目标片段及操作图示，输入框始终接受完整原目标，不拆成多个自动代填字段。普通常驻目标、拼音、释义不计 helpUsed；点击帮助/重播教学以及错误后出现第 2、3 级操作帮助计入，重复播放不重复增加“求助题数”。

## 统计和保存

首次提交分母在该 occurrence 首次有效提交时增加一次，即使后来放弃也保留；刷新重交不再增加。编辑操作按非组字 input 中删除或替换已有文本的一次用户操作记 1，单纯新增记 0；composition 内候选更换不记修改。多字符一次删除仍为一次操作。无法识别时不猜数量，标记本操作统计不可用。不能将它命名为错误字数。

累计记录按语言、任务种类分组；家长可选全部/故事/委托/专项，默认为全部。首次正确与“无帮助首次正确”分别记录，孩子的独立完成次数使用后者。最近表现显示最近 7 个有练习日，与此前 7 个有练习日比较；不足两组只显示当前值，不画虚假增长。沿用既有日历史保留上限；累计统计不随历史淘汰消失。

内容与统计使用 Unicode code point，不按 UTF-16 单元数。语音朗读/常驻提示本身不算输入活动；composition/input/编辑/有效提交沿用 15 秒有效窗口、30 秒无活动自动暂停；自动暂停前组字进行中仅显示非遮挡提示，待组字完成后暂停，避免破坏候选窗口。后台立即暂停，不继续计时。

保存已提交上屏 draft 可合并为 300ms trailing 写入；题完成、暂停、退出、失焦、步骤切换立即 flush。不得承诺浏览器强杀前最后 300ms 永远不丢；已完成题必须先持久化再显示推进。存储不可写时提示内存模式并继续，不伪称保存成功。

完成原子事务：验证租约与 revision → 检查 current instanceId/state → 更新当前题、统计、课程、30/20 币 +（今日首个任务 5 币）→ 标记 result。每日小目标按本地日期判定：与 phase2.dailyBonus.lastDate 不同日才发，并把 lastDate 置为当日、跨日连续时 streakDays+1（断签回到 1）；连击只用于展示，不惩罚、不补发。接受结算仅限当前未结算实例；旧 instanceId 请求永远拒绝，即使短历史已淘汰。首次完成故事另存 72 位集合；重放已完成故事产生新实例。purchase 使用现有事务路径，不复制余额。保存失败时内存结算可显示明确“本次未保存”，重试持久化同一 revision/事务，不能重新加币。

第一阶段的原输入、计时、准确率公式、题目生成与晋级原样保留。新增存档版本取当前 schemaVersion+1；迁移增加空的 phase2 数据以及 activeTask 判别联合。已有第一阶段未完成关转换成 phase1 variant，不丢原 seed、输入位置或结算状态。实现须提供真实旧档 fixture，不只构造空存档。

## 类别与资源数据约定

content.json 中 tags 是项目可参与的练习类别，不等于全部类别立即解锁。uppercase、space、punctuation 在首次含对应字符的英文教学出现后开放；selection 在首次中文选字教学后开放；homophone 从中文 25 开放、polyphone 从中文 31 开放、umlaut 从中文 34 开放。易错专项在对应语言至少有一条失败或显式帮助记录且该项目 learned 后开放。中文每道题始终显示拼音，不能将它当作孩子主动求助。

委托默认混合全部已学内容（2026-11-16 题量下调）：中文只学单字与有词语后均为 12 题；英文只有单词时 12 题，有短句后 9 题。专项固定 6 题。N 在实例创建时固定，不随中途解锁改变。

每个新任务至少保留一条 focus 项题目在各故事步骤中。内容配置版本为 phase2-content-2（2026-11-16 只下调各任务题量，未改任何词句目标；加载时已知的旧版本 phase2-content-1 透明迁移到当前版本并立即持久化，进行中任务使用存档内自带的完整题单，不受影响）；存档记录该版本与完整 target 快照（ID、目标、拼音、释义），资源更新不得使未完成题目标改变。后续内容修改应另发版本，不能复用 ID 表示不同目标。

新增可选存档字段（2026-11-17）：`phase2.dailyBonus`（`{ lastDate, streakDays } | null`）与 `lastTaskResult.dailyBonusCoins`（数字）。旧存档缺 `dailyBonus` 时加载补为 null 并立即持久化；校验对缺失宽容、对存在值严格。居民入住、字词图鉴与下一目标卡都是既有数据（storyDone/learned/余额/商品目录）的派生展示，不新增存档字段。

中文轻声按清单展示，多音字语音按该目标词确定，不能仅按单字 TTS 默认读音。对拼音有异读的系统候选，无论如何选出，只要目标汉字匹配即接受；练习不判孩子拼音输入路径。
