# 第二阶段开发范围

[第二阶段规范](../phase-2/README.md)是本次功能开发的完整入口。范围为 72 个居民故事、中英文输入、长期复习、共享奖励和统计；第一阶段保持原有规则。

配置源：[content.json](../phase-2/content.json)。工程与验收：[HANDOFF.md](../phase-2/HANDOFF.md)。规格检查：[VALIDATION.md](../phase-2/VALIDATION.md)。本记录只索引最终规范，不复制产品规则。
