# 变更规格：小镇地图 3D 化（three.js + R3F 竖切）

状态：已验证（阶段 1+3+4；Safari 真机终审待用户手测）

## 目标和范围

用户希望解决的问题：
小镇地图是 2D 等距 SVG，缺少「迪士尼式童话夜镇」的空间感与探索感。

本次增加或改变的行为：
- 小镇页（P04）地图区在支持 WebGL 的浏览器中改为 3D 连续场景（`src/three/`）：12 座程序化糖果风建筑（每座 6 盏窗灯 + 招牌演出）、四街区 2×2 连续世界（溪桥街小溪木桥 / 星光坡草丘台阶 / 月湾港海面浮标）、运镜（街区页签跳转、进镇聚焦当前建筑）、锁定街区雾罩 + 发光锁牌、OrbitControls 鼠标/触控板漫游（不监听键盘）。
- 建筑卡片成为键盘焦点层（固定停靠条，不随相机同步），沿用 `building-chip` 类名与三态（done/current/later）；3D 内点建筑（射线拾取）与卡片走同一入口，controller 零改动。
- 点建筑去练习增加过渡：3D 下运镜推进 + 画面淡出（≈0.5s）→ 练习页淡入；reduce-motion 与 2D 回退直切。
- 交付基线改为 HTTP（放弃 file:// 双击打开；standalone 单文件产物保留但非主线）。

保持不变的相关行为：
- 打字练习/IME/结算/存档/灯光节/居民任务/商店全部为既有 DOM 代码；练习页沿用 2D `BuildingSvg`；伙伴侧栏仍为 2D `PartnerArt`；存档结构无迁移（`save.buildings` 直接驱动 3D 窗灯）；controller 路由联合与所有入口逻辑未改。

## 行为例子

|前置状态|用户操作或事件|可观察结果|统计/奖励/晋级/建筑影响|
|---|---|---|---|

## 界面与兼容

- 页面及组件复用：TownPage 布局/侧栏/横幅全保留；2D `DistrictScene` 作为回退路径原样保留。
- 正常/锁定/错误状态：锁定街区 = 深色地面 + 紫雾罩 + 锁牌 + 无灯（卡片仍显示解锁条件）；contextlost = 2D + 提示；3D chunk 加载中 = 「3D 小镇加载中…」占位。
- 键盘/触摸/小屏/减少动画：卡片停靠条 Tab/Enter 可达（e2e 复用原断言）；`max-width:640px` 下 chips 换行；OrbitControls 触控板/拖拽；reduce-motion 全场景静态化。
- file:// 与 HTTP：主线 HTTP；file:// 仍可用（单文件 IIFE 含 3D，未验证为支持目标）。
- 存档兼容或迁移：无迁移；同一存档在 2D/3D 间往返一致。

## 阶段 4：Autoresearch 优化段（2026-11-20，分支 autoresearch/size → autoresearch/perf）

台账：`light-town/.auto/log.jsonl`（不入库）；仪表盘快照 `docs/evidence/3d/autoresearch-{size,fps}-dashboard.html`。

**段 A 体积**（metric `firstpaint_gzip_kb`，checks = typecheck + 166 单测）：

| # | 假设 | 结果 | 处置 |
|---|---|---|---|
| 基线 | 单文件 IIFE（合并后 main） | 首屏 499.8KB gzip | — |
| H1 | 移除 standalone 内嵌 + iife 格式 → ESM 分块 | 首屏 240.4（入口 JS 499.8→191.4） | keep `740d095` |
| H2 | assetsInlineLimit 100000→4096，字体外置 | 首屏 240.4→202.2（CSS 48.9→9.7） | keep `91dbe35` |

净效果：**首屏 gzip 499.8→202.2KB（-59.6%）**；3D 场景约 254KB 成为按需 chunk（无 WebGL 浏览器不下载）；字体独立缓存。E09 e2e 适配（拦模块脚本），134 e2e 在两 keep 后各复跑一次全绿。README（两层）改 HTTP-only 口径；file:// 双击交付退役。

| # | 结果 |
|---|---|
| 1–3 | 8.30 / 8.30 / 8.30 ms（p95 ≤10.0，锁 120Hz 节拍） |

结论：远低于 16.7ms 预算（Apple Silicon 60fps 目标），**达标收段，无需优化**；Mac Safari 实测终审留给用户手测。测量脚本 `scripts/perf-orbit.mjs`（measure.sh 自起自停 preview、拒绝软渲染）。
