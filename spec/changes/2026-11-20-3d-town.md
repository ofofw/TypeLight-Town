# 变更规格：小镇地图 3D 化（three.js + R3F 竖切）

状态：已验证（阶段 1+3；阶段 4 体积/帧率优化未做）

## 目标和范围

用户希望解决的问题：
小镇地图是 2D 等距 SVG，缺少「迪士尼式童话夜镇」的空间感与探索感。

本次增加或改变的行为：
- 小镇页（P04）地图区在支持 WebGL 的浏览器中改为 3D 连续场景（`src/three/`）：12 座程序化糖果风建筑（每座 6 盏窗灯 + 招牌演出）、四街区 2×2 连续世界（溪桥街小溪木桥 / 星光坡草丘台阶 / 月湾港海面浮标）、运镜（街区页签跳转、进镇聚焦当前建筑）、锁定街区雾罩 + 发光锁牌、OrbitControls 鼠标/触控板漫游（不监听键盘）。
- 建筑卡片成为键盘焦点层（固定停靠条，不随相机同步），沿用 `building-chip` 类名与三态（done/current/later）；3D 内点建筑（射线拾取）与卡片走同一入口，controller 零改动。
- 点建筑去练习增加过渡：3D 下运镜推进 + 画面淡出（≈0.5s）→ 练习页淡入；reduce-motion 与 2D 回退直切。
- 交付基线改为 HTTP（放弃 file:// 双击打开；standalone 单文件产物保留但非主线）。

保持不变的相关行为：
- 打字练习/IME/结算/存档/灯光节/居民任务/商店全部为既有 DOM 代码；练习页沿用 2D `BuildingSvg`；伙伴侧栏仍为 2D `PartnerArt`；存档结构无迁移（`save.buildings` 直接驱动 3D 窗灯）；controller 路由联合与所有入口逻辑未改。

## 关联

- 源码：`src/three/`（buildings/ 四街区 + parts + 派发器、TownScene、DemoPage、support）、`src/ui/pages/TownPage.tsx`、`src/ui/pages/PracticePage.tsx`（仅根节点淡入类）、`src/styles/global.css`（.town3d* / .page--fadein）。
- 脚本：`scripts/shot3d.mjs`、`shot3d-town.mjs`、`shot3d-building.mjs`、`shot-town3d-live.mjs`、`loop-town3d.mjs`。
- 证据：`docs/evidence/3d/`（街区 ×4、锁区近/远、真页面 ×2、闭环 ×3）。
- 依赖（均 MIT）：`three@0.187.0`（渲染）、`@react-three/fiber@9.8.2`（React 绑定）、`@react-three/drei@10.7.9`（仅用 Line/OrbitControls/Stars）、`@types/three`（开发）。
- 与现有规则冲突及决策依据：构建产物仍为单文件 IIFE（`vite.config.ts` `format:'iife'`，服务 standalone 内嵌），因此 `React.lazy(TownScene)` 在生产包中不产生独立分块——不改构建格式（避免牵动 standalone 交付），体积问题整体移交阶段 4（Autoresearch 段 A 第一假设即「移除 standalone 内嵌 → ESM 分块」）。

## 行为例子

|前置状态|用户操作或事件|可观察结果|统计/奖励/晋级/建筑影响|
|---|---|---|---|
|小镇页（WebGL 可用）|点街区页签|相机运镜到该街区，卡片停靠条切换为该街区 3 座|无|
|小镇页|点建筑卡片或 3D 建筑|运镜推进 + 淡出 → 练习页|与原 2D 入口完全一致（light/replay）|
|练习结算后回小镇|暂停菜单「回小镇」|相机聚焦当前要点亮的建筑；刚点亮的窗呈暖光|`save.buildings` 灯档实时反映|
|浏览器无 WebGL 或 contextlost|进入/使用小镇|自动回退/切回 2D SVG 地图（现有实现），顶部提示一次|无|
|系统或设置开启减少动画|任意|3D 静态呈现（无呼吸/运镜缓动，直接跳转切页）|无|

## 界面与兼容

- 页面及组件复用：TownPage 布局/侧栏/横幅全保留；2D `DistrictScene` 作为回退路径原样保留。
- 正常/锁定/错误状态：锁定街区 = 深色地面 + 紫雾罩 + 锁牌 + 无灯（卡片仍显示解锁条件）；contextlost = 2D + 提示；3D chunk 加载中 = 「3D 小镇加载中…」占位。
- 键盘/触摸/小屏/减少动画：卡片停靠条 Tab/Enter 可达（e2e 复用原断言）；`max-width:640px` 下 chips 换行；OrbitControls 触控板/拖拽；reduce-motion 全场景静态化。
- file:// 与 HTTP：主线 HTTP；file:// 仍可用（单文件 IIFE 含 3D，未验证为支持目标）。
- 存档兼容或迁移：无迁移；同一存档在 2D/3D 间往返一致。
