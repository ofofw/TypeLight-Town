# 本地文件运行验证

日期：2026-11-12。

## 变更

构建输出经典 IIFE 脚本；打包脚本将脚本、样式、字体、图标与全部音频内嵌为 HTML。产物为 `light-town/dist/index.html` 和外层 `点亮小镇/index.html`，可直接双击。开发源码入口 `light-town/index.html` 在 file:// 下自动转到 dist/index.html，在 HTTP 开发模式下仍由 Vite 处理。

文件模式使用内嵌音频；HTTP 模式继续使用随站点分发的音频路径。没有修改游戏规则或存档格式。文件模式与 HTTP 模式存档隔离，文件移动及浏览器差异可能影响本地存档。

## 已执行验证

- `npm run typecheck`：通过。
- `npm test`：97 项通过。
- `npm run build`：通过，两个独立 HTML 已生成。
- `caffeinate -du node scripts/check-standalone.mjs --chrome-only`：Chrome 实际 file:// 启动、伙伴选择、指法引导键盘输入、刷新恢复存档通过；全部 22 个内嵌音频解码通过，无页面脚本错误。
- `caffeinate -du npm run test:e2e -- --project=chrome`：43 项通过。

原脚本下载失败测试已改为模拟内嵌主脚本缺失，验证启动失败提示及重试恢复。
