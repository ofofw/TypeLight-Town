# 素材及音频许可清单

范围：`light-town/` 中随游戏分发的全部内容（即 `npm run build` 生成的 `dist/`），以及只在开发机上使用、不随游戏分发的工具。

结论：游戏里的第三方内容只有三项，都允许免费再分发和商用：Andika 字体（SIL OFL 1.1）、React（MIT），以及用 Kokoro 模型（Apache-2.0）生成的语音。其余图片、音乐和音效都是本项目用代码原创的。许可文本随构建产物一起分发，位于 `dist/licenses/`。

第二阶段新增的中文读音与教学提示（`audio/phase2/voice/*.m4a`，115 个文件）同样由 Kokoro-82M-v1.1-zh 离线合成，许可与第一阶段的语音一致（见第二节）；生活场景动画为代码绘制的原创 SVG。

## 四、再生成与核对方法

- 字体：比较 `src/assets/fonts/` 与 `npm pack @fontsource/andika@5.3.0` 解包后 `files/` 中同名文件的 SHA-256，应完全一致。
- 音乐、音效：运行 `npm run audio`。4 个音效每次生成的文件逐字节相同；音乐的 AAC 文件头里有时间戳，所以每次生成的字节不同，但音频内容相同。
- 语音：见 README“语音生成”一节。第一阶段用 Whisper 逐句校验的结果在 [`evidence/voice-verify.json`](evidence/voice-verify.json)：17 句的拼音音节差异都在 0–6.2% 之间，阈值为 10%。
- 第二阶段语音：`scripts/.venv/bin/python scripts/voice/generate-phase2.py` 重新生成全部 115 个文件；`scripts/.venv/bin/python scripts/voice/verify-phase2.py` 做读音链核对（pypinyin 短语读音 == content.json 拼音，轻声不标调）、文件完整性与时长/峰值检查，结果写入 `.cache/phase2-voice-verify.json`；加 `--asr` 用 Whisper 交叉核对读音（见验收记录的说明）。
