## 启动方法

需要 Node.js 22.12 或更高版本。在 `light-town` 目录中：

```bash
npm ci
npm run build
npm run preview        # 浏览器打开 http://localhost:4173/
```

在 iPad 上玩：Mac 运行 `npm run preview:lan`，iPad 的 Safari 打开 `http://<Mac 的本地主机名>.local:4173/`。详细步骤（包括开发模式、部署和测试）见 [README](../README.md)。

## 实现范围

- **页面**：P01–P12 全部实现，包括锁定、空状态、错误状态和返回路径。
- **小镇**：4 个街区，12 座原创建筑，每座 6 个阶段，另有完成效果和全镇庆祝。已完成的建筑可以从小镇进入重练。
- **伙伴**：暖暖、慢慢、跳跳三个原创伙伴，各有待机、鼓励、庆祝、指引四种表现。
- **装扮**：9 件饰品，以及 2 个付费灯光主题（另有 1 个默认主题）。
- **课程**：12 阶课程（a–z 加空格）和手指映射。三种玩法：逐键点窗、连接灯带（第 2 阶起）、点亮招牌（第 5 阶起）。
- **出题与结算**：按配额出题，同一个键不会连续出现超过 2 次；奖励、建筑进度和课程晋级相互独立，按关卡或轮次 ID 只结算一次。
- **灯光节**：12 座建筑全部点亮后开放，包括三关一轮的易错复习、自选按键的自由练习和灯光主题。
- **家长页**：累计和近 7 天的有效时长、尝试次数、准确率、课程进度，26 个字母加空格的明细，以及最多 5 个易错键；写明“不能判断孩子实际使用了哪根手指”。
- **声音**：一首可无缝循环的原创背景音乐，4 种原创音效，17 句中文语音（开源模型离线生成）。设置可分别开关并调节音量，另有总静音；语音播放时音乐会自动变小。
- **存档**：
  - 本地保存，带备份；存档损坏时自动恢复。
  - 浏览器无法保存时改为内存模式继续玩。
  - 遇到新版本的存档时不覆盖。
  - 同时打开两个页面时，只有一个页面能写入存档。
  - 清除进度需要两次确认。
- **设备**：支持 Mac 和 iPad 的外接键盘，适配横屏、竖屏和 200% 缩放，支持系统的减少动态效果设置，可以添加到主屏幕。

按需求**不包含**：账号、云同步、导入导出、广告、支付、社交、统计分析、个人信息收集，以及 Service Worker 离线缓存。

## 未验证事项

1. **iPad 真机（E04、F04）**：**真机未验证**。拿到 iPad 后按[兼容性报告](兼容性报告.md#ipad-真机未验证)中的 11 项清单检查。这是 E04、F04 仍为“未验证”的唯一原因。
2. **需要在 iPad 上复核的项目**：自动播放限制（E01）、屏幕布局（E05）、切到后台（E07）、按键延迟（E09）、真实中文输入法（B03）、外接键盘的空格（B05）。这些已在 Mac 的 Chrome、WebKit 和真实 Safari 中通过。
3. **Safari 中的三项人工检查**：真正的 Caps Lock 状态、中文输入法组字和声音试听，WebDriver 无法代替。步骤见[兼容性报告](兼容性报告.md#真实-safari自动检查通过)末尾，几分钟就能做完。
4. **试听与换声**：自动检查只能确认音频能播放、字词读对，不能判断听感。建议试听背景音乐、4 种音效和 17 句语音，并审阅[语音台词表](语音台词表.md)。如果想换一种声音，可以先听 `.cache/voice-audition/` 中 8 种女声（`zf_001` 等）读同一句话的试听文件（只在本机，不入库），然后告诉开发方要换哪一种。
