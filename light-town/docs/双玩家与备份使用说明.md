# 双玩家与备份使用说明

双击项目根目录 `index.html`，或打开 `light-town/dist/index.html`。无需安装程序。每次打开先选自己的名字；默认玩家一保留此浏览器已有进度，玩家二从头开始。选择页可改名，两人允许选择同一小伙伴。

游戏顶部和暂停菜单都可以切换玩家。两人的小伙伴、音乐设置、金币、装扮、两阶段课程、统计和未完成任务各自保留。回来后选择继续任务；不会自动开始计时。

## 保存在哪里

日常进度自动保存在当前浏览器的 localStorage 中，不在游戏目录里。浏览器清理数据、切换浏览器或网址、移动文件都可能影响读取原存档。复制文件夹不能隔离或复制进度。同一时刻只允许一个页面游玩；其他页面须明确接管。

如果显示“当前无法保存”，保持页面打开，可重试保存或导出当前内存备份。切换时也可明确选择“暂存本次并切换”，但这只在当前页面有效，关闭会丢失未保存的部分。

## 备份与恢复

1. 在选人页，或设置页，打开“备份与恢复”。
2. 点“导出两人备份”，在浏览器下载位置确认 `点亮小镇-双人备份-日期-时间.json` 已保存。一个文件包含两个人的全部进度、未完成任务和已选好的文字。
3. 恢复时选择 JSON 文件，核对文件中的两个人与当前两个人的进度，点击“恢复这份备份”，再确认整体恢复。
4. 恢复会替换两人全部进度，不合并金币或课程。成功后重新选人。
5. 如恢复错了，在同一页面或重新打开后选择“撤销上次恢复”。它会回到覆盖前的两人进度，并丢弃恢复后新玩的部分；只保留最近一次撤销记录，无重做。

备份包含玩家名字和学习记录，请妥善保管。只能导入本版本导出的双人备份；单人旧档会在原浏览器自动升级。文件大小上限 20 MiB，损坏或不兼容的文件不会覆盖原档。

## 清空一个人的进度

先选中要清空的玩家，进入设置，点击注明其名字的“清空……的游戏进度”，经过两次确认。另一人的进度保持不变；被清空玩家的名字、身份、声音和动画设置保留，小伙伴重新选择。清空同时删除上次恢复的撤销记录。

## 中文输入时

未选定的拼音候选无法保存。请先选好字再导出或切换；切换提示中也可明确放弃这一次未选定的拼音。已经上屏的草稿和任务进度会保留。
